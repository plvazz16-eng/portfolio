# Simulador de Lançamento Oblíquo

Simulador de física desenvolvido em Python para calcular e visualizar o comportamento de um projétil em um lançamento oblíquo.

O projeto utiliza conceitos de cinemática e programação orientada a objetos para calcular tempo de voo, altura máxima, alcance horizontal, posição e velocidade do projétil.

## Funcionalidades

- Cálculo do tempo total de voo
- Cálculo da altura máxima
- Cálculo do alcance horizontal
- Cálculo da posição em diferentes instantes
- Cálculo das componentes horizontal e vertical da velocidade
- Visualização da trajetória do projétil
- Comparação de trajetórias para diferentes ângulos
- Testes automatizados

## Tecnologias

- Python 3
- Matplotlib
- Unittest
- Programação Orientada a Objetos
- Git
